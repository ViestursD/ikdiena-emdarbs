# Tulkojuma sadaļas

Šajā mapē katra OECD ziņojuma nodaļa vai patstāvīga apakšnodaļa tiek glabāta atsevišķā Markdown failā.

Failu numerācija nosaka apvienošanas secību DOCX dokumentā. Saglabā avota virsrakstu struktūru un numerāciju. Tulkojuma progress tiek uzturēts projekta saknes `CHANGELOG.md` failā.

Tulkojuma faili tiek apvienoti šādā secībā:

1. `00-saīsinājumi-un-akronīmi.md`
2. `01-udensapgade-un-kanalizacija.md`
3. `02-udensapgades-un-kanalizacijas-parvaldiba.md`
4. `03-ilgtermina-strategija.md`

`GLOSSARY.md` ir darba terminu vārdnīca un netiek iekļauts gala ziņojumā.

Skatīt arī [GLOSSARY.md](GLOSSARY.md).
